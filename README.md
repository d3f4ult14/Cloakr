# Cloakr - Safer Internet Access

Thank you for using Cloakr.

Safer internet starts with you

What is Cloakr?
Cloakr is a software that filters your internet traffic to the popular network Tor. Tor hides your IP address in 3 different locations. Nowadays, using a VPN can be easily detected and the connection can be interfered, stopped or blocked. Cloakr can connect to Tor without detection!

Browse safely!

HOW TO USE
----------

Run the "Cloakr.bat" file with administrator permissions.
Then you will see a list of options once run:

 (1) Start     connect and route everything via Tor
 
 (2) Stop      back to your normal internet
 
 (3) Restart
 
 (4) Status    details and exit IP
 
 (5) My IP     check your Tor exit IP
 
 (6) Change    get a new Tor identity
 
 (7) Kill      close apps that may leak
 
 (8) Bridges   add and enable Tor bridges
 
 (0) Exit

REMEMBER
--------
-Don't expect the internet speed to be fast
